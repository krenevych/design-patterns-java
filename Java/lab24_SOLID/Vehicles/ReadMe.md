# Vehicles (Транспортні засоби).

У цьому пакеті ви знайдете спроби побудувати універсальну систему 
керування різними типами транспорту: автомобілями, літаками, велосипедами тощо. 
Проте архітектура має серйозні вади, 
які роблять систему нестабільною при додаванні нових моделей.

## Завдання.
Код у цьому завданні демонструє проблеми ієрархії успадкування та порушення принципу 
Liskov Substitution Principle (LSP) та Interface Segregation Principle (ISP). 
Поясніть чому.
Запропонуйте способи вирішення.
