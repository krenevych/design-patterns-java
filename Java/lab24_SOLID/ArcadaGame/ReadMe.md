# Аркадна гра.

Розглядається аркадна гра DOOM. 

У грі беруть участь різні монстри - Зомбі, Демони, Біси (Imps).

Проаналізуйте наведений код.

Які архітектурні принципи та принципи SOLID на Вашу думку порушує наведений код?

Вказівка:
* Дайте відповідь на питання, наскільки легко додавати нові типи монстрів.
* Додайте новий тип монстрів на ігрову сцену (наприклад, Какодемона).
