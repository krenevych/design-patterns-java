# Аркадна гра.

Розглядається аркадна гра DOOM. 

У грі беруть участь різні монстри - Зомбі, Демони, Біси (Imps).


## Завдання
1. Проаналізуйте наведений код. Які архітектурні принципи та принципи SOLID на Вашу думку порушує наведений код?
2. Дайте відповідь на питання, наскільки легко додавати нові типи монстрів.
   * Додайте новий тип монстрів на ігрову сцену (наприклад, Какодемона).
3. Які б зміни, Ви здійснили в першу чергу, дотримуючись основних принципів ООП.

## Додаткове практичне завдання «Рефакторинг на папері»
1. Намалюйте спрощену UML-діаграму поточного (поганого) стану.
2. Намалюйте діаграму, як би ви розділили відповідальність після застосування принципів SOLID.
